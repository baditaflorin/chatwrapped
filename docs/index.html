How do I export my chat?

WhatsApp: open a chat → ⋮ / contact name → Export chat → Without media. You get a .txt file.

Telegram (Desktop): open a chat → ⋮ → Export chat history → format Machine-readable JSON. You get a result.json.

Everything runs locally with the browser's FileReader. Open your devtools Network tab if you want to confirm nothing is sent.
